# homebrew-tap

Homebrew tap

## Roxel

```sh
brew install --cask starzonmyarmz/tap/roxel   # the Roxel app (macOS)
brew install starzonmyarmz/tap/rox            # the rox command-line tool
```

`Formula/rox.rb` and `Casks/roxel.rb` are generated by
[Roxel](https://github.com/starzonmyarmz/roxel)'s release workflow from its
`packaging/homebrew/` folder. Edit them there, not here.
